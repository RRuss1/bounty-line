# Art

Source files for original artwork: the Bounty Line logo, the wanted-poster template, and
the PAID / CLAIMED / EXPIRED stamps. Original or CC-licensed only, never ripped Blizzard art
(design spec Section 11.2). Credit CC assets here and in the main README.

- [`poster/`](poster/README.md): the blank parchment the bot draws wanted posters on, with its size spec and layout guide.
